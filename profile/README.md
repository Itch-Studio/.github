itch.studio is a one-person app studio of John Durcan
([@JohnnyD1776](https://github.com/JohnnyD1776)), a senior iOS engineer in
Farnham, UK.

Six apps built end to end, five live on the App Store: PoeticÁI, UI Colour
Palette Designer, Bluetooth Itch, Aura Pool and Bark Back with TimerStack 
in beta. The studio also runs fixed-price iOS App Health Checks, monthly 
care plans, and AI feature sprints for client apps.
